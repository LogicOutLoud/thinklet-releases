THINKLET — START HERE

This guide is for the Mac app download.
Thinklet requires macOS 13 (Ventura) or later.
The universal Mac download supports Apple silicon and Intel Macs.

1. CHECK YOUR DOWNLOAD
   Download the Mac app ZIP from:
   https://github.com/LogicOutLoud/thinklet-releases/releases
   Choose a package that matches your Mac:
   - mac-arm64: Apple silicon (M1, M2, M3, M4 or newer).
   - universal: Apple silicon or Intel, when available.
   See Apple menu > About This Mac to check your chip.
   The release page lists the minimum macOS version and available packages.

   GitHub's green Code > Download ZIP and its Source code links contain this
   repository's instructions, not Thinklet.app. Download the app ZIP under
   the release's Assets instead. If there is no app asset, it is not available
   yet; do not try to build or install this documentation repository.

2. OPEN THE DOWNLOAD
   In Finder, double-click the downloaded app ZIP to extract Thinklet.app.
   If you downloaded the DMG, open it and use the Thinklet.app inside it.

3. INSTALL
   Quit an older copy of Thinklet if it is open.
   Drag Thinklet.app into Applications in Finder's sidebar.
   If updating, replace the older app in Applications. Your existing Thinklet
   settings and library are kept separately from the app.

4. OPEN
   Open Applications, then double-click Thinklet.
   If macOS asks whether to open an app downloaded from the internet, confirm
   only if this is the package you downloaded from the official repository.
   If macOS says the app is damaged, cannot be verified or contains malware,
   stop and contact support. Do not turn off Gatekeeper or delete quarantine.

5. CONNECT YOUR AI
   Follow Thinklet's welcome screen and choose Connect your AI.
   You can use a supported AI account, your own API key or a private local AI.
   Enter any credentials inside Thinklet or the provider's sign-in page.
   Never post a password or API key in a GitHub issue.
   You can change your connection later in Settings > AI & accounts.

6. FUTURE UPDATES
   Thinklet checks after launch and every three hours, and downloads updates
   in the background. Choose Restart and install inside Thinklet when ready.
   You can also use Settings > Help & About > Updates > Check now.
   Ordinary quitting never installs an update.

NEED HELP?
   Use Thinklet's Help menu or email chris@logicoutloud.com.
   For installation problems, include your macOS version, chip and the exact
   error text. Leave out private conversations, passwords and API keys.

REMOVE THE APP
   Quit Thinklet and move Thinklet.app from Applications to the Trash.
   This does not erase your saved Thinklet data. Do not delete data folders
   unless you separately intend to remove your library and settings.
