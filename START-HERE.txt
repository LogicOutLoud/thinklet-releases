THINKLET - START HERE

Official downloads:
https://github.com/LogicOutLoud/thinklet-releases/releases/latest

Choose a package for your operating system and processor. The Mac universal
download supports Apple silicon and Intel Macs on macOS 13 or later. Windows
and Linux have separate x64 and ARM64 packages.

MAC
Open the DMG or extract the app ZIP. Quit an older Thinklet, then drag
Thinklet.app into Applications. Replace the app when updating; your library
and settings live separately. Open Thinklet from Applications.
The Mac app is Developer ID signed and Apple-notarized. If macOS reports a
damaged, unverifiable or malicious app, stop and contact support. Do not
disable Gatekeeper or remove quarantine.

WINDOWS PREVIEW
Windows packages are unsigned previews. Windows may warn about or block them,
especially with Smart App Control. Do not disable security protections.
Choose the x64 installer for Intel/AMD PCs, or ARM64 for an ARM-based PC.
Run the installer; it installs for your account and adds Thinklet to Start.
For the portable ZIP, extract the entire folder and run Thinklet.exe.

LINUX
On Debian or Ubuntu, install the .deb with your software installer, or use:
  sudo apt install ./Thinklet-linux-amd64.deb
Use the ARM64 filename on an ARM64 computer. Launch Thinklet from your apps menu.
For AppImage, allow the downloaded file to run as a program. If dependencies or
sandbox restrictions prevent launch, use the .deb where supported or contact
support. Extract a portable archive fully before running cabinet-next.

CONNECT YOUR AI
Follow the welcome screen and choose Connect your AI. Use a supported AI
account, your own API key or a private local AI. Enter credentials only inside
Thinklet or the provider's sign-in page. Never post credentials in an issue.
Available integrations depend on your operating system.

UPDATES
Use Settings > Help & About > Updates. Choose Restart and install when offered.
Portable archives and Debian packages may require installing the next download.
Ordinary quitting does not install an update. Saved data lives separately.

GITHUB SOURCE ZIP
Code > Download ZIP and Source code links download this repository's
instructions, not an app. Use the app files under a release's Assets.

HELP
Use Thinklet's Help menu or email chris@logicoutloud.com. Include your OS,
processor and exact error text; leave out passwords, keys and conversations.
